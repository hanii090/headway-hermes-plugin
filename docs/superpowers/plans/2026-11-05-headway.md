# Headway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Detect varied Hermes tool calls with no observable progress and inject a recovery packet.

**Architecture:** A dependency-free deterministic engine fingerprints local workspace state and normalized results. A thin public Hermes adapter wraps `tool_execution`, handles `pre_llm_call`, and registers status/reset/mode surfaces.

**Tech Stack:** Python 3.10+, stdlib, pytest; optional FastAPI router supplied by Hermes.

## Global Constraints

No core patches, network, credentials, or self-updater. Production does not invoke shell/git. State stays under plugin_data_dir. Demo alone uses subprocess. No PR.
